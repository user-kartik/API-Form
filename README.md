# React Project

This is a React-based web application that displays user details and allows for API interactions to fetch random user details. The app consists of multiple components and pages to showcase various functionalities.

## Features

- **Home Page**: A simple homepage with navigation buttons.
- **Form Page**: A form page where users can enter data.
- **API Page**: Fetches random user details from the API and displays them in a styled card.
- **UserCard Component**: Displays a user’s profile picture and details in a styled card layout.

## Technologies Used

- React 
- React Router DOM for navigation
- CSS for styling
- Fetch API for getting data

## Setup

### Prerequisites

Make sure you have `node` and `npm` (or `yarn`) installed. If not, install them from [Node.js official website](https://nodejs.org/).

### 1. Clone the Repository

Clone this repository to your local machine:

```bash
git clone https://github.com/user-kartik/API-Form.git
cd API-Form
```

## 2. Install Dependencies
Install the required dependencies:
```bash
npm install
```
## 3. Run the Development Server

Start the development server:
```bash
npm start
```
The app will run locally on http://localhost:3000.
